MUSICBOX MIDI MANAGER

MUSICBOX-MIDI FS-01 用の MIDI ファイルの圧縮と試聴
MIDI ファイル (このアプリで圧縮した .GZ も可) をここにドラッグ&ドロップ (複数可。追加した順に並び、その順に演奏します。順番は表の ▲▼ で入れ替えられます)
データは外部に送信されません。全てこのコンピュータ内で処理されます

?これから追加する曲の上限の既定値です。曲ごとの上限は表の演奏時間の欄で変えられます。曲ごとの開始の秒と速度 (%) も同じ欄で指定できます。開始より前を切り、開始から上限より長い曲はその時刻で打ち切ってから圧縮します (上限は開始からの演奏時間)。開始と上限は元の速度 (SPEED = 100) での秒です。速度の欄か「この曲の設定」欄で SPEED (TEMPO) を指定すると (両方あれば「この曲の設定」欄が優先)、表の演奏時間の欄と LENGTH は実際の演奏時間になります。試聴中の時刻にマウスを合わせると、元の速度での時刻も表示されます。
MIDI.TXT (表の順に SONG(1) から並べたもの。SONG(0) は空けてある) ?保存した .GZ ファイルと MIDI.TXT を同じ UDisk に置くと、SONG(1) から順に演奏します。 試聴は VOL推奨の値で鳴らしており、MIDI.TXT の SONG(n).ALL.VOLUME はその値です。 打ち切った曲は SONG(n).LENGTH に開始からの演奏時間を書き、終わりの 2 秒をフェードアウトします。 「この曲の設定」欄に書いた行は、先頭に SONG(n). を付けてその曲の行の後ろに追加し、試聴と WAV にも反映します (例: CH(2).VOLUME = 3)。同じキーの = は「この曲の設定」欄の行が優先されます。 

  



「この曲の設定」欄の書き方 (クリックで開く)

MIDI.TXT の行の先頭の SONG(n). を省いて、1 行に 1 つずつ書きます。例えば MIDI.TXT の SONG(1).CH(1).VOL=3 は、「この曲の設定」欄には CH(1).VOL=3 と書きます。
# から行末は注釈です。値が範囲外の行や書き方に誤りのある行は無視されます (欄では赤で示します)。


SPEED=120          # 演奏速度 (%)。50〜200、100 が元の速さ。TEMPO とも書ける
CH(1).VOL=3        # CH1 の音量 (dB)。-30〜+12。+6 でほぼ 2 倍、-6 でほぼ半分。VOLUME とも書ける
ALL.VOL=-6         # 全チャンネルの音量 (dB)。CH(n).VOL はこれに加わる
CH(3).TRANS=-12    # CH3 の移調 (半音)。-48〜+48。-12 で 1 オクターブ下。TRANSPOSE とも書ける
CH(2).INST=FLUTE   # CH2 の音色を固定する。INSTRUMENT とも書ける



INST に書ける値:


    

  • 音色名: TUNINGFORK, XYLOTONE, SAW, CLARINET, SQUARE, PIANO, VIOLIN, FLUTE, ORGAN
    • 

  • ドラム名: BASS (バスドラム), SNARE, TOM, CLOSEDHAT, OPENHAT (CH10 以外のチャンネルでドラムを鳴らす)
    • 

  • GM の音色番号 1〜128 (内蔵の音色に置き換える)、MUTE (鳴らさない)、OFF (固定を解除)
    • 



CH(10) の INST は無視されます。曲の開始位置 (START) と演奏時間 (LEN) は、欄には書かずに表の演奏時間の欄で指定してください
(開始より前を切ってから圧縮するので、欄に START を書くと、切った位置からさらに進んだところから演奏します)。
FILE の行は自動で書くので、欄には書きません。
